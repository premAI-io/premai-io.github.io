Fluso dev-harness benchmark

How current models perform on one comparable knowledge-work workload

This Tier 2 release compares 6 models on the same 78 scored cases from a broader 93-case knowledge-work suite spanning connectors, planning, memory, observability, and longer multi-step workflows.

This release is workload-specific. It measures end-to-end task completion on one comparable dev-harness case set, not universal model quality.

DeepSeek V4 Pro leads this release at 89.7% overall. The stricter check is the trusted subset at 90.5%, while provisional covers the rest of the scored set at 89.5%.

Kimi K2.6 is the lowest-cost comparable run. Cost, p95 wall time, and execution issues help qualify the headline score.

Benchmark

What the benchmark measures

This dev-harness Tier 2 release measures whether models complete realistic tasks end to end, not just whether they sound correct.

Core question

Can the model complete useful knowledge-work tasks end to end, with the right tools, under the same harness rules?

Pass condition

A case passes when the model finishes the requested work, not when it only writes something plausible or stops one step short.

Why the task mix matters

The suite spans 9 task families because useful work is broader than chat quality. Memory, planning, observability, and connector execution all matter, and the result remains specific to this workload mix.

Summary

What the results show

A short summary before the tables and charts.

DeepSeek V4 Pro currently tops the comparable release set on overall task completion. Kimi K2.6 is the cheapest run in the group.

Read three numbers together: overall for the headline, trusted for the stricter evidence-backed subset, and provisional for the rest of the scored set.

Start with the score split

Overall, trusted, and provisional together show whether the ranking holds when you lean harder on the stricter subset.

Then check cost and latency

Close scores can still imply different operating tradeoffs once you include p95 wall time and total cost.

Then read the model notes

Those notes show where each model is strongest, where it drops cases, and whether the trusted subset materially trails the headline score.
